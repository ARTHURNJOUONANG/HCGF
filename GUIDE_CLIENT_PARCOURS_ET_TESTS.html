1. Code de sécurité PD — pourquoi et comment

Le code PD est un second secret (en plus du mot de passe), demandé seulement pour Contrôleur et Administrateur.

Pourquoi : protéger le bureau si un mot de passe fuit ; ne pas le mettre dans le mail ; rotation automatique à chaque nouveau compte équipe ou partenaire (l’ancien code meurt).

ÉtapeQuiQuoi
1AdministrateurCrée un compte équipe / partenaire
2PlateformeAffiche lien (1 h) + nouveau code PD
3PlateformeEnvoie le lien par e-mail (si Resend OK)
4AdministrateurNote le code PD (jamais dans le mail)
5–6Nouveau compteLien → mot de passe → connexion avec le nouveau PD
7—Ancien code invalide pour tout le monde

2. Commun à tous les services

Chaque service ouvre un dossier isolé (référence, pièces, paiement, messages séparés). Le candidat ouvre via Nouvelle ; le partenaire via Initier. L’équipe suit dans le bureau. Ce qui change, ce sont les étapes et le document final.

AVI Formulaire → Documents → Paiement → Validation Dossier final signé (PDF / HTML) Contrôleur (conformes) puis Administrateur
Assurance Formulaire → Tarification → Paiement → Attestation Attestation / police d’assurance Candidat souscrit ; attestation après paiement
Hébergement Formulaire → Matching → Documents → Signature Choix de logement + suite documentaire Matching ≤ 40 min ; pièces ; signature logement
Vol Recherche → Passager → Hold → Justificatif Justificatif Hold (billet non émis) Hold avec date limite ; pas de signature AVI

3. Parcours détaillé par service

3.1 AVI / justificatif financier

Pays ouverts (démo) : France, Allemagne, Belgique, Canada.

Candidat → formulaire + pièces + paiement
Contrôleur → pièces « Conformes »
Administrateur → rapproche fonds → Signer
Candidat → Document final
  1. Nouvelle → AVI → pays → Continuer.
  2. Formulaire (identité, établissement, dates, montant AVI).
  3. Pièces : passeport, admission, justificatifs financiers.
  4. Paiement : virement déclaré (référence).
  5. Bureau contrôleur : ✓ Conforme sur chaque pièce.
  6. Bureau administrateur : rapprochement fonds puis Signer.
  7. Candidat : bandeau Document final → télécharger.

Quatre yeux : la personne qui contrôle ≠ celle qui signe.

Vente croisée : sur un dossier AVI, bandeau pour ouvrir une assurance isolée (identité / dates reprises).

3.2 Assurance voyage

Pays ouverts (démo) : France, Allemagne.

Formulaire → choisir formule → payer → émettre / télécharger l’attestation
  1. Nouvelle → Assurance voyage → pays → Continuer ou depuis un AVI : « Ajouter une couverture voyage ».
  2. Formulaire : identité + dates de séjour + formule (essentielle / confort / premium).
  3. Onglet Assurance : choisir une formule → souscrire.
  4. Onglet Paiement : régler / déclarer le virement (rapprochement bureau si besoin).
  5. Émettre l’attestation (bouton) puis télécharger la police.
  6. Pièce passeport si demandée dans l’onglet Pièces.

Pas le bouton « Signer » AVI de l’administrateur : ici c’est l’attestation assurance.

3.3 Hébergement

Pays ouvert (démo) : France.

Formulaire → Matching (≤ 40 min) → choisir logement → documents → signature
  1. Nouvelle → Attestation d’hébergement → France → Continuer.
  2. Formulaire : identité, établissement, date de rentrée.
  3. Onglet Logement : lancer le Matching (logement à ≤ 40 min de l’établissement).
  4. Choisir un logement proposé (ou liste d’attente si besoin).
  5. Onglet Pièces : déposer le passeport (et autres pièces si demandées).
  6. Suivre l’étape signature / validation prévue pour le logement.
  7. Bureau : contrôle des pièces et suivi du dossier comme pour les autres services.

3.4 Vol (Hold / Pay Later)

Pays ouvert (démo) : France (offre vol).

Recherche d’offres → passager → Hold → justificatif (billet non émis)
  1. Nouvelle → Réservation de vol → Continuer.
  2. Formulaire : identité + aéroports / dates.
  3. Onglet Vol : consulter les offres ; si Hold autorisé → Hold.
  4. Compléter le passager si demandé.
  5. Noter la date limite de paiement (Hold).
  6. Générer / télécharger le justificatif « Réservation confirmée – billet non émis ».
  7. Suivi aussi dans Mes réservations de vol (menu Vols).

Ce n’est pas une signature AVI. Le Hold peut expirer si non payé à temps.

5. Comment tester (checklist)

Test A — AVI jusqu’au document final

  1. Candidat : AVI France → formulaire → 3 pièces → virement VIR-DEMO-1.
  2. Contrôleur : ✓ Conforme sur chaque pièce.
  3. Administrateur : rapprocher → Signer.
  4. Candidat : télécharger Document final.

Test B — Assurance

  1. Candidat : Nouvelle → Assurance → France (ou vente croisée depuis AVI).
  2. Remplir dates + choisir formule → souscrire.
  3. Paiement (virement + rapprochement si besoin).
  4. Émettre / télécharger l’attestation.

Test C — Hébergement

  1. Candidat : Nouvelle → Hébergement → France.
  2. Formulaire établissement + date.
  3. Matching → choisir un logement.
  4. Déposer le passeport ; suivre la suite documents / signature.

Test D — Vol

  1. Candidat : Nouvelle → Vol.
  2. Renseigner départ / arrivée / dates.
  3. Onglet Vol → Hold sur une offre éligible.
  4. Justificatif + page Vols.

Test E — Messages / partenaire

  • Message candidat ↔ contrôleur sur un dossier.
  • Partenaire Initier un AVI pour candidat.demo@avi.test → commission visible au bureau.

6. Points d’attention

  1. AVI = seul parcours avec Signer administrateur + quatre yeux.
  2. Assurance / Hébergement / Vol = étapes propres ; dossiers toujours isolés.
  3. Fonds reçus avant signature AVI.
  4. Code PD change à chaque invitation équipe / partenaire.
  5. Paiements externes (PayPal, Mobile Money…) encore souvent en démo.

7. Checklist globale

  • ☐ AVI : document final candidat
  • ☐ Assurance : attestation téléchargeable
  • ☐ Hébergement : matching + logement choisi
  • ☐ Vol : Hold + justificatif
  • ☐ Messages bureau
  • ☐ (Option) apport partenaire
